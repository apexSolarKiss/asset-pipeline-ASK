## Pre-Registered Fork Outcomes with Observable Discriminators

The fork resolves into one of four outcomes:

### Premise holds // terminal curation event

Observable across moments:

- Operator did NOT consider multiple plausible alternatives upstream
- Selected concept-instantiation did NOT add normative direction beyond input derivation
- Reference selection / generation-direction-setting did NOT materially reshape instantiation
- Curation created the real authorship moment
- Eight-step protocol shape fit each moment uniformly

### Premise refines // layered discretionary chain

Observable:

- Multiple plausible scenario-instantiations considered and rejected upstream
- Selected instantiation added normative direction beyond input derivation
- Reference / generation-direction maintained the upstream choice
- Curation ratified upstream authorship rather than originated it
- Eight-step shape fit upstream and curation moments cleanly

### Premise fragments // multiple authorship-bearing seams

Observable:

- Multiple authorship moments at varying strengths upstream + curation
- Reference / generation-direction MATERIALLY reshaped upstream concept
- Curation contradicted, redirected, or composed with earlier seams
- Different protocol moments needed different record shapes (eight-step skeleton fragments under operational pressure)

### Failure to resolve

Observable: protocol records inconclusive; evidence too gentle to discriminate; test design under-pressured the fork. Named failure-mode IS a finding (test-design weakness vs evidence-too-gentle vs architecture-already-resolves).

## Pre-Registered Falsification Conditions

Findings are honest if they meet at least one of:

- A fork outcome is supported by clear protocol-record evidence
- A specific strain point bites in a way the architecture explicitly predicted
- The test fails to resolve, with named reasons (test-design weakness vs evidence-too-gentle vs architecture-already-resolves)

Findings are NOT honest (warrant rerun or reframe) if:

- Protocol record is post-hoc rationalization rather than captured-in-flight
- Operator's subjective experience replaces protocol's structural shape as the resolution mechanism
- Strain points are dismissed without contact with operational evidence
- Fork outcome is chosen for narrative coherence rather than evidence weight
