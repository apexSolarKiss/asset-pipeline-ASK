## What This Artifact Attempts

The six category columns are now complete. Each deepening answered: *what does this input category contribute to the IA, at what layer, with what constraints?* The cross-category question is row-shaped rather than column-shaped: which category carries which kind of normative force; which validates or overrides another; which produces structural content; which produces prose-rich interpretive content; where carrier pressure concentrates; where operator judgment remains load-bearing; where the brand-system layer's structural decision is sharper than before.

The artifact answers four integrated questions:

1. **What does each of the six categories uniquely contribute, in functional terms, when read across the set?**
2. **How do the six categories relate to each other — where do they validate, contradict, supersede, operationalize, demonstrate, abstract, constrain, inherit, defer, or fail to answer?**
3. **What does the integrated set imply about the extraction sequence PR #241 named?**
4. **What does the integrated set imply for the brand-system layer's structural decision, without resolving it?**

The synthesis is a conceptual integration, not an authorization. It clarifies the integrated intake model the six-category set implies; it does not promote schema, modify the structured IA model v1, edit the architecture front door, or authorize any operational test. Per ASK direction and per the workflow rule that synthesis attempts must pressure against concrete examples without becoming planning artifacts, the artifact pressures the model against the four worked-example modes lightly while honoring the uneven evidence depth across them.

Three integrated observations the matrix surfaces:

- **The four-bucket classification (evidence / articulation / application / validation) maps cleanly onto the six categories with one bucket each — except that brand platform and photography style guide both occupy "articulation" while serving different functions (propositional identity vs photographic conventions).** The architecture treats them as distinct categories because the content shapes differ; the synthesis surfaces that the four-bucket classification is finer than the six-category enumeration but distinguishes function rather than content shape.

Directive-force is broadly distributed (every category except asset library carries directive content somewhere). Governance-force concentrates in asset library metadata + application guidelines per-touchpoint approval rules + past-campaigns governance trace. This concretizes the brand-system layer's named decision from a fifth angle (the prior four deepenings each concretized it from a different angle).

## Cross-Category Relationship Model

The six categories relate to one another through a vocabulary of nine relations. Each relation names a way one category bears on another in the intake architecture; the relations compose to form the dependency graph downstream operational pressure would test.

### Relation vocabulary

- **Validates.** Category A's content cross-checks Category B's content; where they align, B's content is operationally confirmed; where they diverge, the validator surfaces an integrity question (typically resolved per visual-as-fidelity-strategy or per temporal-state classification).
- **Contradicts.** Category A's content disagrees with Category B's content. Resolution depends on the architecture's fallback chain — typically asset library carries against prose articulation; newer carries against older; current carries against superseded.
- **Supersedes.** Category A's content replaces Category B's content as operational authority — the older content retains continuity-reference value but loses operational authority.
- **Operationalizes.** Category A takes Category B's content and converts it into operational rules — Category A is downstream of Category B in the operational chain; without A, B's content lacks per-surface specificity.
- **Demonstrates.** Category A shows what Category B articulates — visual evidence demonstrating articulated convention; historical execution demonstrating stated guideline; library imagery demonstrating brand platform stance.
- **Abstracts.** Category A is the abstraction layer above Category B — Category A names what Category B executes; Category A's content shapes interpretation of B's evidence.
- **Constrains.** Category A bounds Category B's operational space — A names what B's content must respect; B operates within A's boundaries.
- **Inherits.** Category A's content extends Category B's content downstream — A applies B's rules in a more specific context; A's content presumes B's content as upstream baseline.
- **Defers.** Category A does not answer the question Category B addresses — A leaves the territory to B; intake should not look to A for content B is responsible for.

The vocabulary is descriptive, not prescriptive. Real intake encounters relations in combination — past campaigns simultaneously *validate* application guidelines, *contradict* parts of brand platform, and *supersede* outdated photography style guide rules in one archive.

### Named relations across the six categories

Selected relations the synthesis earns from the deepenings. Not exhaustive; the architecturally load-bearing pairs are named, not the full N×N.

**Asset library and photography style guide.**

- Asset library *validates* photography style guide articulated conventions where execution matches articulation.
- Asset library *contradicts* photography style guide where execution diverges from articulation; per visual-as-fidelity-strategy, asset library carries (the photography deepening's load-bearing fallback closed by the asset-library deepening).
- Asset library *demonstrates* photography style guide conventions; photography style guide *abstracts* asset library demonstration. The pair is bidirectional — each side names what the other carries.
- Photography style guide *fails to answer* the question of conventions implicit in the library but never articulated. Where the brand operates by sustained pattern without writing it down, asset library carries the convention; photography style guide is silent.

**Asset library and brand platform.**

- Asset library *demonstrates* brand platform stance (visual evidence shows how the brand has operated against its stated values).
- Asset library *contradicts* brand platform when articulated values diverge from demonstrated behavior; per visual-as-fidelity-strategy, demonstrated behavior carries.
- Brand platform *abstracts* what asset library demonstrates at the values / voice / stance level — without brand platform articulation, library posture must be inferred interpretively.
- Brand platform *fails to answer* the operational question of which library segments are current vs historical; the library carries its own temporal context.

**Asset library and VIS.**

- Asset library *validates* VIS constants applied across imagery (color application; typography overlay; logo placement).
- Asset library *contradicts* VIS where execution bent or extended constants (a one-off color in a campaign; typography hierarchy bent for editorial reasons).
- VIS *constrains* asset library's downstream interpretation — constants bound the application space the library evidences.
- VIS *fails to answer* photographic-content questions (subject treatment; environment; styling) — defers to photography style guide.

**Asset library and application guidelines.**

- Asset library *validates* stated mode-activation in application guidelines (library segmentation by touchpoint reveals which modes the brand has actually operated in).
- Asset library *contradicts* application guidelines when stated touchpoint set excludes touchpoints the library evidences, or vice versa.
- Application guidelines *operationalize* asset-library evidence into per-touchpoint rules — without application guidelines, library segmentation is descriptive but not operational.

**Asset library and past campaigns.**

- Asset library and past campaigns *overlap* at the imagery layer (per the past-campaigns deepening's nested-clarification): asset library is imagery as population; past campaigns are execution-units of which imagery is one element among campaign-world, arc, channel-propagation, governance, and outcomes.
- Past campaigns *contextualize* asset-library imagery with the execution-unit envelope (which campaign produced which assets; what role each played).
- Asset library *flattens* past-campaigns context when the library does not preserve campaign-association metadata.

**Brand platform and VIS.**

- Brand platform *abstracts* what VIS instantiates at the visual-constants level — values inform palette choices; voice informs typography selection; stance informs logo treatment.
- VIS *operationalizes* brand platform's visual implications — the constants are the visual instantiation of platform abstractions.
- Brand platform *fails to answer* per-medium specification questions (hex codes; clear-space rules; type scale) — defers to VIS.
- VIS *fails to answer* values / voice / stance questions — defers to brand platform.

**Brand platform and photography style guide.**

- Brand platform *abstracts* what photography style guide instantiates at the photographic-treatment level — stance toward subject shapes camera distance; voice shapes lighting register.
- Photography style guide *operationalizes* brand platform's visual implications at the image-production layer.
- Brand platform *fails to answer* lighting / composition / framing questions — defers to photography style guide.

**Brand platform and application guidelines.**

- Brand platform *abstracts* the authority posture application guidelines articulates per-touchpoint.
- Application guidelines *operationalize* brand platform authority / decision posture into per-touchpoint approval rules.
- Brand platform *fails to answer* per-touchpoint application questions — defers to application guidelines.

**Brand platform and past campaigns.**

- Past campaigns *demonstrate* brand platform stance in execution across multiple campaign worlds.
- Past campaigns *contradict* brand platform when accumulated execution diverges from stated values / voice — typically a sign that brand platform articulation is performative or stale.
- Past campaigns *supersede* brand platform articulation when articulation is older than recent campaign work and the executed work demonstrates a more current operating posture.
- Brand platform *abstracts* what past campaigns demonstrate.

**VIS and photography style guide.**

- VIS *constrains* photography style guide content at the visual-constants intersection (typography in image overlay; color treatment of materials; logo placement within imagery).
- Photography style guide *operationalizes* VIS constants in image-production conventions.
- VIS *fails to answer* image-production questions outside the constants intersection; *defers* to photography style guide.

**VIS and application guidelines.**

- VIS *constrains* application guidelines at the per-touchpoint constants application (which color codes per channel; which typography per format).
- Application guidelines *operationalize* VIS constants per touchpoint.
- VIS *fails to answer* per-touchpoint operational questions outside the constants — defers to application guidelines.

**VIS and past campaigns.**

- Past campaigns *demonstrate* VIS constants applied at campaign scale.
- Past campaigns *contradict* VIS when campaigns bent or extended constants (one-off color extensions; typography hierarchy bends for editorial reasons); resolution depends on whether the bend was sanctioned or off-policy.
- Past campaigns *validate* VIS constants when sustained execution across campaigns matches articulated constants.

**Photography style guide and application guidelines.**

- Photography style guide and application guidelines *overlap* at the per-channel / per-touchpoint image-treatment intersection.
- Application guidelines *operationalize* photography style guide channel adaptations into per-touchpoint operational rules.
- The two *contradict* when photography style guide channel adaptations and application guidelines per-channel rules articulate different rules for the same touchpoint; typically application guidelines carries at the touchpoint-constraint layer (aspect ratios; copy-overlay tolerance) while photography style guide carries at the photographic-treatment layer (lighting; composition).

**Photography style guide and past campaigns.**

- Past campaigns *demonstrate* photography style guide conventions at campaign scale.
- Past campaigns *contradict* photography style guide when campaign-world pressure bent conventions; resolution depends on whether the bend was sanctioned (campaign-world expression) or drift (uncontrolled deviation).
- Past campaigns *validate* photography style guide when sustained execution across campaigns matches articulated conventions.

**Application guidelines and past campaigns.**

- Past campaigns *validate* stated mode-activation in application guidelines (do past campaigns actually exist for the modes application guidelines name?).
- Past campaigns *contradict* application guidelines when stated touchpoint set diverges from cross-campaign touchpoint inventory.
- Past campaigns *supersede* application guidelines when stated rules predate significant operating-reality shifts the campaigns evidence.
- Application guidelines *fail to answer* historical-pattern questions; defer to past campaigns.

### Three integrated observations the relationship model surfaces

- **Asset library and past campaigns are the two evidence-shaped categories; the other four are articulation-shaped or application-shaped.** Every articulation-shaped category (brand platform; VIS; photography style guide) is validated, contradicted, or superseded by one or both evidence categories. Application guidelines occupies a middle position — it is forward-looking and prescriptive (articulation-shaped) but operationalizes the articulation-shaped content into per-surface form, and past-campaigns evidence validates whether its operationalization matches operating reality. The architecture's load-bearing fallback (visual-as-fidelity-strategy) is the asset-library-carries side of this evidence-vs-articulation pattern; past-campaigns content adds a temporal-conditional version (current-execution-carries; superseded-execution becomes continuity reference).
- **Brand platform abstracts and defers; past campaigns demonstrate and supersede.** The two categories sit at opposite ends of the evidence-vs-articulation axis. Every other category sits between them: VIS, photography style guide, asset library, and application guidelines each mediate between brand platform's propositional content and past campaigns' executed evidence. The synthesis surfaces that the six-category set is not flat — it has an evidence-vs-articulation poles structure with three categories along each axis (brand platform → VIS → photography style guide on the articulation axis; asset library → past campaigns → application guidelines as application-evidence-validation triad on the operational axis).
- **The "fails to answer" relation is symmetric between every category pair and is the architecture's clearest signal of category boundaries.** Each category fails to answer questions that fall in another category's territory; intake should not look to a category for content outside its functional role. The negative-shape of the relation model — what each category does *not* carry — is as architecturally load-bearing as what each does carry.

## Extraction-Sequence Pressure

PR #241 proposed a seven-stage extraction sequence: `evidence → articulated conventions → abstraction → application → validation → defaults → inference/authorship`. Now that all six categories are deepened, the sequence holds at default but pressures in three specific conditions.

### Does evidence-first still hold?

Yes, at default. The architecture's structural-carrier distribution still concentrates at the evidence layer (`reference_assets`; per-SKU `product_image`; lookup chain; `asset_attachment`). Stage 1 // Evidence populates structural carriers most directly; subsequent stages flow into prose carriers with operator-mediated translation. The synthesis confirms PR #241's evidence-first default; it does not propose a wholesale reorder.

### When does validation need to move earlier?

In two named conditions where Stage 5 // Validation (past campaigns) is more operationally credible than Stages 2 // Articulated Conventions and 3 // Abstraction:

- **Stale-articulation case.** When articulated input categories (brand platform; VIS; photography style guide) predate significant operating-reality shifts that past-campaigns evidence reveals, Stage 5 should be read against Stages 2–3 *before* downstream stages absorb the stated content. Otherwise the downstream IA absorbs articulation that does not reflect current operating reality. The architecture's existing fallback (current carries over older; visual-as-fidelity-strategy) still applies; the sequence-level adjustment is *when* validation pressure surfaces, not *what* resolution rule applies.
- **More-operationally-credible-than-current-docs case.** When the articulated input categories are sparse, outdated, or contradictory and the past-campaigns archive is rich and coherent, Stage 5 becomes the architecture's primary source rather than its validation surface. The operator may use Stage 5 evidence to backfill what Stages 1–4 should articulate. The sequence becomes Stage 5 first, then Stages 1–4 derived against Stage 5 evidence, then Stage 6 // Defaults and Stage 7 // Inference/Authorship.

In both conditions, the sequence is not strictly linear; Stage 5 functions as a conditional jump-point.

### When do past campaigns outrank current articulation?

Per the past-campaigns deepening: when temporal-state classification places past campaigns as *current operating reality* and articulated content as *historical / superseded / performative*. The visual-as-fidelity-strategy precedent (asset library carries when prose contradicts) generalizes to a temporal-conditional version (current execution carries when older articulation contradicts). The architecture's existing fallback chain accommodates this; the synthesis surfaces that the relation is not just visual-as-fidelity-strategy but a broader execution-as-fidelity-strategy that past-campaigns evidence extends.

### When does application logic mediate between evidence and abstraction?

Per the application-guidelines deepening: application guidelines occupy Stage 4 // Application and translate brand-platform authority posture (Stage 3 abstraction) into per-touchpoint constraints that operate against asset-library evidence (Stage 1) and photography style guide conventions (Stage 2). Application is the operational hinge between abstraction and evidence — without application guidelines, brand-platform authority cannot be operationalized per-surface, and asset-library evidence cannot be evaluated against per-touchpoint constraints. The synthesis surfaces that Stage 4 is not optional in the sequence; it is load-bearing where the brand operates across multiple touchpoints.

### Where does operator-authored content become unavoidable?

PR #241 named operator-authored content as architecturally distinct from inferred-not-stated. The synthesis surfaces that operator-authored content becomes unavoidable in two conditions:

- **Thin-across-multiple-categories case.** When the brand has thin evidence (sparse asset library; sparse past campaigns) *and* thin articulation (sparse brand platform; sparse VIS; sparse photography style guide; sparse application guidelines), Stage 7 // Inference/Authorship runs against insufficient input from every prior stage. The operator authors brand-system content from scratch using worked-example defaults plus systemic patterns plus interpretive judgment.
- **New-touchpoint case.** When the brand operates an established system at a touchpoint application guidelines do not name and no past-campaigns evidence covers, intake produces operator-authored content for the new touchpoint even when other intake stages are well-populated. Stage 7 becomes a per-touchpoint back-stop, not only a final-stage fallback.

### Refinement, not replacement

The synthesis refines PR #241's sequence rather than replacing it. The sequence's default direction holds; the conditional jump-points (validation-first under stale or operationally-superior past-campaigns evidence) and the back-stop pattern (Stage 7 as per-condition back-stop, not only end-stage fallback) are *behaviors within the sequence* the deepenings now make explicit. The architecture's intake graph is the seven-stage sequence with conditional ordering and back-feedback edges; PR #241's linear ordering is the default traversal direction within the graph.

## Brand-System Structural-Decision Pressure

The brand-system layer's structural decision (named at milestone 9; three live shapes — first-class throughout / terminal operator-mediated / hybrid; hybrid most likely on current evidence per the hybrid carrier decision surface v1) is sharpened by the six-category synthesis. The synthesis does not resolve the decision. It surfaces the contours.

PR #241 named a three-zone hybrid implication if hybrid is the surviving shape: structural carriers for stable brand-wide constants + approved references; operator-mediated translation for prose-rich directive content; an unresolved third zone of intake-time judgment trace. The synthesis sharpens this to a five-or-six-zone implication, where each zone reflects a distinct carrier pressure the six-category set produces.

### Zone 1 — Stable brand-wide constants + approved references

Strongest structural-carrier candidate zone. Content from VIS (logo references; color codes; typography assignments; grid systems) plus asset library (approved reference imagery) wants structural representation. `reference_assets` is the existing partial carrier for the approved-references half of this zone; brand-wide constants beyond approved references (color codes; typography assignments; logo files) still have no first-class home. Per the VIS deepening, the constants are concretely defined entities that occupy the same gap brand platform abstractions occupy from a different angle.

### Zone 2 — Prose / operator-mediated translation for abstraction and articulated conventions

Brand platform abstractions (values; voice; stance; audience; promise; authority; narrative themes; exclusion boundaries) plus photography style guide articulated conventions (ten dimensions per the photography deepening) plus VIS applied conventions (the seventh VIS component) flow downstream as operator-interpretive guidance into prose carriers (`creative_intent`; `bounded_creative_discretion`; `slot_prompt`; `capture_reason`; `capture_notes`). The synthesis confirms this zone's prose-character; structural carriers for abstraction and articulated conventions are not earned and would risk encoding a representation the architecture has not pressured.

### Zone 3 — Per-touchpoint and per-mode constraint structural representation

Application guidelines content paper-presses two structural-carrier candidates the synthesis sharpens: **aspect-ratio-as-attribute** on slots (per the marketing- and campaign-mode Phase 1 sketches plus the application-guidelines deepening) and **per-touchpoint approval-rule structural representation** (per the application-guidelines deepening). Held composite-anchor candidates for marketing (`messages` / `briefs`; structured slot-message-element fields; `selection_axis`) and campaign (`campaign_concept`) sit adjacent to this zone — they would absorb application-guidelines content for marketing and campaign modes if earned. None of these is earned by the synthesis; the zone names where carrier pressure concentrates without authorizing carrier creation.

### Zone 4 — Governed-output continuity reference elevation

Past-campaigns content uniquely pressures the governed-asset layer (per PR #239's ninth reference function, governed-output continuity reference). The current architecture treats `reference_assets` as independently linkable, so a past-campaign governed output can be linked as a reference for new work — but the derivative-governance question (what governance applies to the derivative; when reuse is authorized; how the brand's reuse rules from application-guidelines content interact with the past-campaign asset's original approval scope) is held across all four modes per the apex artifact. The synthesis surfaces this as a distinct carrier zone: a governed-output-as-continuity-reference structural elevation beyond the existing flat `reference_assets` linkage.

### Zone 5 — Temporal-state trace dimension

Past-campaigns content uniquely pressures temporal-state classification (current / historical / superseded per content piece). The past-campaigns deepening surfaced this as a candidate sixth trace dimension beyond PR #241's five (presence-of-inspection; articulation-state; chain-position; derivation-basis; contradiction-resolution). The synthesis confirms temporal-state trace is distinct from the five and concentrates entirely at the past-campaigns intake site — though the temporal logic generalizes to any input category that evolves over time (which is potentially any category for a long-lived brand). The zone's structural representation remains held.

### Zone 6 — Intake-time judgment trace zone

PR #241's third hybrid zone. Carry-forward; the synthesis does not change this zone's status. Intake-time judgment trace remains uncovered by current carriers; held candidates (`articulation_state`; `derivation_basis`; `fallback_chain_position`; `contradiction_log`; PR #241's operator-authored fifth derivation-basis value; the past-campaigns-deepening temporal-state trace candidate) are paper-pressed and bound to a scale condition (multi-operator or continuity-breaking intake) untested.

### What this implies, named

The six-category set sharpens the brand-system layer's structural decision from PR #241's three-zone implication to a five-or-six-zone implication. No single shape (first-class throughout / terminal operator-mediated / hybrid) carries all six zones cleanly. If hybrid is the surviving shape, the synthesis surfaces that the hybrid is itself layered — six zones each pressing toward different carrier behavior. The decision remains held; the synthesis sharpens the surface.

## Four-Mode Implications

The synthesized model pressures lightly against the four worked-example workflow modes. Evidence depth is uneven (full-flow operational at SKU and collection; bounded full-flow at campaign; structural-proof at marketing); the pressure surfaces what intake stage-load looks like per-mode against the six-category stack.

### SKU-driven mode

- **Stage-load concentration.** Stage 1 // Evidence carries heaviest (asset library populates `reference_assets`; per-SKU `product_image` is the architecture's primary fidelity strategy). Stages 2 // Articulated Conventions (photography style guide) and 4 // Application (per-product-photography touchpoint constraints) carry moderately. Stages 3 // Abstraction and 5 // Validation carry lightly.
- **Cross-category load.** Asset library + photography style guide + per-SKU product-truth content dominate. Brand platform, VIS, application guidelines, and past campaigns add contextual content without changing the mode's operational shape.
- **Carrier pressure.** Within Zone 1 (stable brand-wide constants + approved references). The mode is the architecture's cleanest operational evidence for the visual-as-fidelity-strategy claim; structural carriers are over-served here relative to other modes.
- **Operational evidence depth.** Full-flow operational at PKT-SKU-007 / 009 / 010.

### Collection / merchandising mode

- **Stage-load concentration.** Stages 1 // Evidence + 2 // Articulated Conventions carry the family-coherence reference content. Stage 4 // Application supplies the collection-axis intake. Stage 5 // Validation is load-bearing when past campaigns include collection-shaped work.
- **Cross-category load.** Asset library + photography style guide + application guidelines + past campaigns load together. Brand platform and VIS load lightly.
- **Carrier pressure.** Zone 1 (asset library content) + Zone 2 (photography style guide articulated conventions). The collection-mode operational deflation showed prose discipline carries cross-slot consistency under operational pressure; structural carriers for collection-mode are not earned.
- **Operational evidence depth.** Full-flow operational at PKT-COLL-001.

### Marketing / message-driven mode

- **Stage-load concentration.** Stage 4 // Application carries heaviest (marketing mode is touchpoint-shaped at every slot; application guidelines is the dominant content source). Stage 1 // Evidence is partial. Stage 3 // Abstraction and Stage 5 // Validation are load-bearing where the brand has promotional past campaigns.
- **Cross-category load.** Application guidelines + asset library + past campaigns + brand platform load together; photography style guide and VIS load moderately.
- **Carrier pressure.** Zone 3 (per-touchpoint and per-mode constraint structural representation) is the mode's load-bearing pressure surface.
