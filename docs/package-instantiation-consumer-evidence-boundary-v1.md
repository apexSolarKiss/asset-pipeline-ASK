# Package-Instantiation Consumer — Evidence Boundary v1

## Posture

```text
evidence-boundary artifact, not architecture expansion
records what a formal calibration proved and what it explicitly did NOT prove
not a consuming grammar, not a general converter, not a schema
not a repeatable-consumer claim
not a second-target / portability claim
self-superseding if a later run revises the boundary
```

## What was tested

Milestone 14 named the open question — *what consumes a package* — after the repo's deployment-diagnostic application grammar tested as the **wrong consumer** for a package instance ([`docs/consuming-artifact-test-findings-v1.md`](consuming-artifact-test-findings-v1.md), 10/10 category-mismatch). This result names a **first operational consumer** and bounds its evidence: a **package-instantiation planning agent**. A formal calibration test asked whether a fresh agent could derive a faithful instantiation brief from the portable 2c package ([`docs/portable-package-extraction-2c-marketing-hero-v1.md`](portable-package-extraction-2c-marketing-hero-v1.md)) plus one declared, known-achievable filesystem target — **without seeing the prior filesystem instantiation** ([`docs/worked-package-store-2c-marketing-hero/`](worked-package-store-2c-marketing-hero/)). Blind, two independent runners, value-exact source bundle.

## What held (the earned claim)

Formal calibration **passed**. Both runners produced faithful, fully source-and-target-cited instantiation briefs; classified gaps (e.g. image-pending references, aggregate-only candidates) **instead of inventing**; kept selection distinct from governance; and treated no prior-instantiation enrichment as source truth. The earned claim, stated exactly:

> A package-instantiation planning agent can, on one known-achievable filesystem target, derive a faithful package-to-target instantiation brief from the portable package alone, without seeing the prior filesystem instantiation, preserving source depth and classifying gaps instead of inventing.

## What it did NOT prove

```text
no consuming grammar (one package, one target, two runners — run 1 only)
no second-target portability; no general converter
no consuming-grammar, schema, or general-converter canon; no runtime
next-evidence condition: a materially different second target before any grammar talk
```
